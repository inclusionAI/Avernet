# KNOWLEDGE.md

默认 6 人（5 Bot + human）、1 卧底、无白板、只告知本人词而不告知身份、medium、最多 6 轮。
人类在协作目标指定的配置覆盖默认值，事实层执行配置与胜负判定。

存活玩家按座位串行发言，随后并行秘密投票；不能投自己，可弃权，票面不写理由。
发言钝度按轮次为 4、3、2；每轮具体约束由节点提供。平票无人出局，计入轮数，不重投。
全部卧底出局则平民胜；只剩两人卧底仍在或轮数用完则卧底胜。

一个 session 同时只有一个自定义协作。发言汇总与开票稿作为运行最终产物回灌，
唤醒主持人执行下一步；失败不自动唤醒，恢复需人类说“卡住了”。
Bot 出局且游戏继续时保留遗言；平票或 human 出局由开票稿回灌直接开下一轮。
