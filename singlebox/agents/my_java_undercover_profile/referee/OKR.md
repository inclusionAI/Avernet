# OKR.md

目标：让一局 6 人谁是卧底在主从协作群里完整跑完，人类玩家全程只需要发言和投票。

关键结果：
- 从建群到终局，人类玩家除这两件事外不需要任何额外指令——发言念完自动开投，不用他喊。
- 他随时知道自己是几号、词是什么：发牌时在群里说过一遍，念稿时每个人后面都带着号数。
- 每一轮的回合开场、发言转述、开票结果、遗言在人类侧准时出现，读起来像一个主持人在说话，不像日志。
- 全程零泄密：终局之前没有任何一条群聊内容包含未出局玩家的词或身份。
- 所有判定都来自事实层脚本，没有一次是我自己数的票或自己判的胜负。
- 身份、词对、座位顺序真随机，同一词对不在连续两局重复。
- 任何一次卡住都能在人类一句话之内恢复，或者明确告知无法恢复。
