# 将当前对话生成的文件登记到会话文件列表

## 文件写入请求需要使用本 Skill

即使用户只说“生成一个 helloworld.txt 文件，内容为你好”，也应使用本 Skill。
在完成文件写入任务前读取这些说明，即使一次 `write` 调用就能生成整个文件。
文件登记属于输出交付的一部分。

在最终回复成功之前，完成两步：

1. 完成用户要求的文件写入。
2. 使用下文随附的 CLI，将该路径登记到**当前会话**。

写入工具成功不等于整个任务完成。不要等用户再次要求登记、上传或提供文件链接。
如果无法完成登记，应说明“文件已保存，但未加入会话文件列表”，并说明失败原因或缺少的可信会话信息。
不能仅凭写入成功就声称文件已登记。

当前对话生成或修改的输出文件完成写入后，自动调用随附 CLI，将它加入当前会话文件列表。
无需用户再次发出发布指令或确认。“只保存在本地”本身不表示拒绝登记。
等待写入完成，再登记当前任务产生的各个输出路径；修改已有文件并保存后也适用。

上述默认行为是模型加载本 Skill 后应遵循的指令。本 Skill 不负责安装或激活自身、
监听文件系统或部署运行时变更。只处理当前任务已知的输出路径。

用户明确要求不要登记、附加、发布或加入会话列表时，应对指定文件或任务尊重该要求。
纯读取操作（读取、预览、列出、下载或没有写入输出文件的分析）、未完成文件和临时中间文件均不登记。
不要监听文件系统、扫描历史工作区文件，或发布无关的已有文件。
用户明确要求将某个指定的已有文件加入当前会话时，仍可执行。

## 执行步骤

1. 直接调用下方 CLI，让它读取运行时为**本次工具执行**注入的 `HITL_SESSION_KEY`。
   模型不需要读取或填写会话标识，不要给命令添加 `--session-key`，也不要设置、导出或覆盖该环境变量。
   不得使用 `current`、`latest`、`default` 等占位符，不得从会话历史、最新会话、文件、时间戳或示例猜测身份。
   不要枚举环境变量来查找会话信息，以免读取凭据。
   如果 CLI 报告缺少或无效的当前会话上下文，应说明文件已保存但未加入列表，然后停止。
   不通过手工补填、切换会话或绕过校验来伪造成功。
2. 确认目标是已完成写入的普通文件，并取得相对于**实际运行时 workspace 根目录**的路径。
   不要写死企业环境的工作区路径。文件指代不明确时，询问具体文件。
   不传绝对路径、父目录跳转路径、目录或符号链接；Engine 负责校验路径边界，并登记原路径的实时引用。
   不复制独立快照，也不为登记读取凭据或文件字节。
3. 找到本 Skill 的安装目录，即包含此 `SKILL.md` 的目录，通过 Python 调用随附 CLI。
   正确引用参数，或使用 subprocess 参数列表：

   ```text
   python3 <本Skill目录>/scripts/teamclaw-session-file publish <工作区相对路径>
   ```

   将尖括号占位符替换为真实值。无需配置 PATH，也不需要 Backend/Gateway 凭据。
   默认使用本机 Engine 地址；只有明确配置了其他本机 HTTP 回环地址时，才使用 `--engine-url` 指定。
   不向远端地址发送请求，也不跟随重定向。
4. CLI 会先提交登记，再用同一会话标识查询文件列表，核对返回资源 ID 且状态为 ready。
   读取 stdout 中的 JSON。只有同时满足以下条件，才能回复登记成功：
   退出码为 `0`、`ok: true`、`code: published`，且 `file.availability: ready`。
   使用 `display_name` 和 `resource_id` 标识文件，并说明已加入当前会话文件列表。
   保留 workspace 原文件。登记的是原路径的实时引用：同一会话内同一路径在编辑或安全原子替换后，
   资源 ID 保持不变，元数据及后续读取反映当前原文件。移除会话关联会保留原文件。
   已有 BaaS 导出链接仍对应其导出时的版本；修改后需要发起新的下载请求来获取新内容。
   如果提交成功但列表核验失败，应说明登记结果尚未确认，不声称已加入列表；不要自动重试。
   其他失败报告稳定错误码，以及存在时的 HTTP 状态码，不声称发布成功。
   不无限重试，不回退到其他会话或需要凭据的其他 API。

## 触发示例

- “生成一个 TXT 文件，内容为你好。”
- “生成 PDF 并保存到本地。”
- “修改昨天的报告，保存修正后的版本。”
- “生成 CSV。”
- “把生成的报告加入当前会话文件列表。”

先完成生成或编辑，再调用 CLI；由运行时当前会话环境决定登记作用域。不要等待用户补充“也发布一下”。

## 不登记的示例

- “读取之前的报告。”
- “展示当前会话文件列表。”
- “下载这份报告。”
- “生成 PDF，但不要加入当前会话文件列表。”
- 在工作区发现了与当前任务无关的历史文件。
