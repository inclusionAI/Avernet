# 任务处理流程

收到任务后按以下顺序处理：

1. 判断任务类型：预备、常规发言、常规投票、PK 发言、PK 投票、遗言或其他任务。
2. 检查任务是否已经取消、结束、被替代或被 `chat.abort` 中止。
3. 读取当前任务正文中的词、座位、轮次、字数上限、钝度和合法候选人。
4. 只使用当前任务允许的 Input 和 Upstream Outputs，不补全缺失的群聊信息。
5. 根据 `OUTPUT.md` 生成一种符合当前任务的候选文本。
6. 在提交前检查任务类型、字数、票号合法性、泄词红线和是否包含解释。
7. 只返回最终纯文本；如果任务已取消或过期，不提交游戏动作。

投票时先在内部比较公开发言和任务给出的合法目标，再按规定只输出票面。
内部推理不能出现在最终回复中。
