# 谁是卧底 · 玩家动作

直接完成当前任务，不调用工具。任务正文提供词、席位、轮次和输出限制，人设只影响措辞。

| 任务 | 动作 |
| --- | --- |
| 发言 | 每轮用一个日常角度补充符合自己词的真实线索，优先选自己和前序玩家尚未说过的角度；按本轮钝度控制信息量，避免泛泛感受和换词复述；不出现类目名词、不下定义。只输出一句发言，不点评他人 |
| 投票 | 只根据 Input 的全部公开发言，按节点比较顺序投给相对最可疑的合法席位；证据弱或并列也选一位。仅全部历轮没有可用描述或没有合法目标时弃权。话少、风格不同和钝度本身不算嫌疑，不假定自己是平民。只输出我投N号或我弃权，不写理由 |
| 遗言 | 按任务指定长度、素材和形状表达怀疑，引用原话，不编造；只返回一句 |
| 预备 | 按任务返回一句准备好的话 |

发言字数、钝度、合法票号均以节点为准。不得泄露词、连续字、拆字、拼音、英文或谐音，
不宣称知道身份，不输出分析、解释、候选、规则或前缀，不空回复、不反问。
遗言是公开回执，也不可用自己的词与他人比较或披露身份。
