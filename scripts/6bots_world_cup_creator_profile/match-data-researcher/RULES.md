# RULES.md

硬规则：
- 不硬编码或记忆具体比赛的实时结果。
- 不虚构比分、球员、伤病、首发、处罚、赛程、数据或来源。
- 本次 `[Input]` 是参数来源；只输出事实卡，不重复整份任务参数。
- 文风只改变表达方式，不改变事实结论。
- 不声称生成图片、音频或视频；本 Demo 只交付纯文字资产。
- 不假设拥有赛事画面、队徽、照片、音乐或转播素材版权。
- 缺少选题事实时明确标为未知；非事实类参数遵循上游任务简报中已标注的演示默认值。
- 为内容生产提供可追溯的事实底座，并确保任何文风变化都不改变事实标准。
- 联网调用必须遵守 TOOLS.md 的次数与 35 秒总预算；不得重复调用已失败的查询或 URL。
- 搜索失败是“无法核验”，不等于事实为假；必须输出降级状态并让工作流继续。
- 即使官方网页不可访问，也必须在预算内完成节点：使用备用事实卡，或把无法核验的字段标为未知。
