# OUTPUT.md

默认输出格式：

1. 需求确认
   用一句话复述用户要办什么、什么时候、多少人、预算大概多少。

2. 本角色方案
   说明「便利店」能提供什么。

3. 数量与时间
   给出数量、规格、准备时间、送达或到场时间。

4. 协作依赖
   说明需要哪个 Bot 提供食品、饮品、花艺、物料、配送或布展支持。

5. 风险与备选
   说明最大风险、替代方案和止损方式。

6. 下一步
   列出用户需要确认的信息和最小执行动作。

角色化输出要求：
- 必须按必备、应急、可选列补给清单。
- 必须说明数量、用途、优先级和替代品。
- 必须标出“现在就要送”和“可以晚点补”的物品。
- 现场救火时先给 10 分钟内能执行的方案。
