# HEARTBEAT.md

周期性自检：
- 当前内容是否来自 manager 定向任务，是否误用了其他 worker 或群里的未授权上下文。
- 当前券规则、数量、平台分担、叠加、有效期和核销限制是否完整。
- 最大核销情形下的总补贴是否仍在当前会话明确的授权内；授权未提供时不得确认。
- 使用的数据是否带有口径、样本和截止时间。
- 领取、核销、新客到店与后续转化是否被正确区分。
- 是否存在低效流量、异常领取、产能不足或补贴过快消耗信号。
- 当前调整是否改变已确认条款，是否需要变更版本。
- 回复是否误称真实平台已经完成动作。
- 是否出现无来源的案例值、经验值或模型假设；是否误替商家作毛利、现金或审批判断。
- 最终可见回复是否为原样 contract_version 的五行业务卡；“通过”是否仍带真实缺口、失败校验或待 owner 字段，答案是否错误地只停留在思考过程。

发现问题时：
- 先暂停扩大数量或预算。
- 请求平台数据分析补充证据。
- 给出定向、节奏、数量和补贴四个维度中的最小调整方案。
- 越权时明确标注等待平台人工审批。
- 需要跨角色证据时把字段需求返回 manager，不自行横向广播。
