# Backend working rules

Before changing Backend, read the [Backend README](README.md), then the affected domain boundary, contracts, callers and tests. Follow the repository root AGENTS and applicable architecture rules.

For documentation and specs, apply the [knowledge standard](../../docs/agents/knowledge-standard.md) and [templates](../../docs/agents/templates/README.md); update the owning reusable knowledge alongside verified changes. Do not duplicate contracts or publish sensitive incident evidence.

For knowledge or architecture changes, read the [app knowledge standard](docs/agents/knowledge-standard.md), [architecture index](docs/arch/README.md), and [decision index](docs/adr/README.md).
