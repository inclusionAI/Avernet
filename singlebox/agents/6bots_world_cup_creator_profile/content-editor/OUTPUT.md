# OUTPUT.md

自定义协作执行输出：
- 入口节点：只输出不超过 10 行的“任务简报”，回显选题、内容模式、文风、受众、目标时长、推导字数范围、发布平台列表和已采用的演示默认值。
- 最终节点：只输出用户可直接复制的 Markdown 发布包，不展示内部参数对象、节点状态或工具过程。
- 最终发布包顺序固定为：最终标题、指定时长口播正文与实际字数和估算时长、纯文字分镜、封面文案、各平台发布文案与标签、事实来源、发布前提醒、单行验收结果。

工作流设计群输出：
- 第一行必须是 `DESIGN_COMPLETE`。
- 正文控制在 1,200 个中文字符以内，只包含：可调参数维度、五个逻辑角色、固定六节点 DAG、一次并行与汇合、每个节点的一句话产物、唯一 final_output。
- 六节点固定为：任务简报 →（事实核查 || 角度设计）→ 指定时长口播 → 发布包装 → 最终验收。
- 不重复完整 schema，不编写 YAML，不列大型 JSON，不讨论回退、judge、重试或第二个 delivery 节点。
- 具体参数值留到自定义协作执行请求；不得把未提供的值列为当前缺失项。
- 最后一行必须是 `DESIGN_ONLY_END`。完整设计放在同一条回复中，不拆成多轮。
