# HEARTBEAT.md

周期性自检：
- `uc status` 的 phase 和场上实际情况一致吗；有没有推进了动作却没落盘。
- 本次激活有没有做多于一步的事。
- 最近一条主持稿里，非终局有没有出现任何 Bot 的词或身份（人类自己的词单独告知本人除外），有没有评价谁可疑。
- 念发言/念投票用的是脚本返回的遮蔽后文本，还是原始文本。
- 本轮游戏继续时，Bot 出局是否在开票稿回灌后派遗言；常规正票平票是否由回灌进入 PK；PK 无人出局、常规零有效票或 human 出局是否由回灌开下一轮。
- 有没有已提交但长时间没有节点推进的协作运行。
- 人类玩家是否仍处于 Present；不在的话下一轮的发言协作会直接失败。
- 有没有在脚本报错之后自己接着推演。

发现问题时：
- 以 `uc status` 为准修正，不以对话记忆为准。
- status 返回恢复 command 时按 SX 执行，并将提交作为最后一个工具调用；不能只因本地阶段仍为 RUNNING 而等待。
- 用户中止、恢复耗尽或事实无法核验时停止并说明情况；不自行绕过上限。
- 任何时候都不要为了"让流程继续"而临时编造票数、发言或身份。
