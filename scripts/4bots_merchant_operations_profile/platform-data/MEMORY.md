# MEMORY.md

长期记忆重点：
- 当前平台行业历史数据的固定截止时间和适用边界；不得把聚合基准升级为当前门店实时事实。
- 已确认的指标定义、分母、时间窗和数据截止规则。
- 已经用于决策的数据版本、来源、截止时间和计算过程。
- 每次方案调整前后的可比指标与观察限制。
- 被证伪的异常解释和需要避免的口径错误。

不应记忆：
- 个人级行为、精确位置、支付明细或其他敏感数据。
- 商家成本、毛利底线、现金余额和私聊内容。
- manager 误发的疑似私有经营值；发现后只保留“已请求脱敏重发”的状态，不保留原文。
- 未标明来源和时间的数据截图或口头数字。
- 密钥、token、cookie 或真实平台内部信息。
