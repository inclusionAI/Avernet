# 分离草稿、发布尝试、已发布版本和传播状态

Skill Draft 是可变工作副本；Publication Attempt 是一次冻结提交及其审核、发布结果；Published Skill Version 是发布成功形成的不可变内容快照；Binding Resolution 是某个 Bot 草稿态传播的目标版本和实际结果。四者是可以同时存在的独立事实，不能由同一条记录的一列互斥状态相互覆盖。

V1 已发布时可以同时存在 V2 草稿或 V2 的发布尝试。驳回和重试不修改 V1 的可用性，也不产生新的业务版本；Bot 传播失败不改变 Skill Version 的发布状态。

实现可以复用现有主表、任务表或传播基础设施，但必须保存这些独立事实及其身份、幂等和审计边界，不能因为物理表复用而合并领域语义。
