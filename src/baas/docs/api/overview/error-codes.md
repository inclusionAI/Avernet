# 状态码登记表（Code Registry）

> 所有响应统一用 `Envelope`（`{code, message, data, request_id}`，见
> `openapi/_shared.yaml`）。`code` 是 **6 位整数 = HTTP 状态码(3) + 业务子码(3)**。
> 本页是业务子码的**权威登记表**：同一个 `code` 全局含义唯一，客户端可据此映射文案/处理逻辑。

## 规则

- 前 3 位 == HTTP 响应状态码。客户端可只看前 3 位做粗粒度处理，看完整 6 位做细粒度处理。
- 后 3 位是业务子码：`000` 为该状态的**默认/通用**含义；`001+` 为具体业务原因。
- 成功也带 code：`200000` 成功、`201000` 创建成功。
- 子码全局唯一：同一 6 位 code 在任何接口含义一致。
- **`message` 一律为英文**（包括成功，成功通常为 `"OK"`）。`code`/字段名/枚举值等机器契约保持英文/字面。

## 通用默认码（`_shared.yaml` 错误响应）

| code | HTTP | 含义 |
|---|---|---|
| `200000` | 200 | 成功 |
| `201000` | 201 | 创建成功 |
| `400000` | 400 | 入参非法（通用） |
| `401000` | 401 | 未认证（API Key 缺失/无效，或 Buservice 会话未登录） |
| `403000` | 403 | 无权限（通用） |
| `404000` | 404 | 资源不存在（通用） |
| `409000` | 409 | 资源状态冲突（通用） |
| `429000` | 429 | 超出配额 / 频率限制 |
| `500000` | 500 | 服务端未预期错误 |

## 分组专属子码

### 开放 API（open-api）

| code | HTTP | 含义 |
|---|---|---|
| `400001` | 400 | 无效的 BCN 下行链路请求格式 |
| `404001` | 404 | 指定的 Bot 或 session 不存在 |
| `429001` | 429 | API 调用频率超限 |
| `502001` | 502 | Bot 引擎响应超时或不可达 |

### Bot 生命周期与管理（bots）

| code | HTTP | 含义 |
|---|---|---|
| `400002` | 400 | Bot 名称或配置参数非法 |
| `404002` | 404 | 指定 Bot 不存在 |
| `409001` | 409 | Bot 名称已存在或状态冲突 |
| `409002` | 409 | Bot 当前状态不允许执行该操作（如重复创建发布） |
| `429002` | 429 | Bot 数量或关联设备超上限 |

### 发布流水线（publishes）

| code | HTTP | 含义 |
|---|---|---|
| `400003` | 400 | 发布请求参数非法 |
| `404003` | 404 | 指定发布记录不存在 |
| `409003` | 409 | 发布状态不允许执行该操作（如非 PENDING 的审批/执行） |
| `500001` | 500 | 发布阶段执行失败（如 PaaS 设备操作异常） |

### Bot 运行时（bot-runtime）

| code | HTTP | 含义 |
|---|---|---|
| `400004` | 400 | 命令参数非法 |
| `404004` | 404 | Bot 设备不存在或未关联 Bot |
| `502002` | 502 | Bot 设备命令执行超时 |

### Bot 文件传输（bot-runtime file-transfer）

| code | HTTP | 含义 |
|---|---|---|
| `400010` | 400 | 文件传输参数非法（路径、大小、分片参数等） |
| `404010` | 404 | 设备或传输记录不存在 |
| `500004` | 500 | 文件传输 OSS 操作异常 |

### PaaS 设备管理（paas-devices）

| code | HTTP | 含义 |
|---|---|---|
| `400005` | 400 | 设备操作参数非法 |
| `404005` | 404 | 指定设备不存在 |
| `404011` | 404 | 中继会话不存在 |
| `500002` | 500 | 设备创建失败（Provider 异常） |
| `503001` | 503 | 资源不足，无可用设备容量 |

### 本地 PaaS（local-paas）

| code | HTTP | 含义 |
|---|---|---|
| `404006` | 404 | 本地机器或用户不存在 |

### 配置管理（config）

| code | HTTP | 含义 |
|---|---|---|
| `400006` | 400 | 配置参数非法 |
| `404007` | 404 | 指定配置/租户/模板/QPM 配置不存在 |
| `409004` | 409 | 配置键名已存在（租户名/系统配置键/模板名等重复） |

### Bot 健康检查（health-checker）

| code | HTTP | 含义 |
|---|---|---|
| `400007` | 400 | 健康检查参数非法 |
| `404008` | 404 | Bot 或设备不存在 |
| `500003` | 500 | 健康检查内部执行异常 |

### 管理后台（admin）

| code | HTTP | 含义 |
|---|---|---|
| `400008` | 400 | 管理操作参数非法 |
| `404009` | 404 | API Key 不存在 |
| `409005` | 409 | API Key 状态冲突（非 ACTIVE 状态下不允许操作） |
