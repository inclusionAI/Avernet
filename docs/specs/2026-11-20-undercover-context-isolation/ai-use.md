# AI 使用策略报告

## 分工

- 人工完成活动认领、GitHub Fork、云燕 IDE 内的克隆和分支创建。人工运行了单人流程快照测试和公开副屏参数测试，并参与起草威胁模型的前两段。
- 使用 Codex 排查 IDE 操作障碍，辅助阅读 Issue、维护者回复和源码，整理可见性矩阵、拟定 RFC，并在本地复跑基线测试。

## 验证与缺口

- 基线测试固定在 `oss-camp2026 @ 86252c1e9`。Ubuntu WSL 的 51 项裁判测试通过（含单人流程快照），Windows 的副屏 `npm run verify` 通过。在一次独立测试运行中往公开副屏输出临时加入假词，相关断言按预期失败。取消注入后通过。
- 区分源码推导、实测结果和设计目标。私有读取路径、不同真人的任务绑定以及真实多人游戏的验收仍需在实现后验证。题目要求的多人复盘和演示必须来自实际运行。
- 参考其他队伍的公开进展来定位重叠工作及待评审项。其测试结果不计入本次提交的验证记录。
