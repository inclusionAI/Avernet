# Flow template

## Record

Record the trigger and scope, participants, ordered steps, state ownership, failure branches, contracts and source/test references. Identify version and evidence limitations.

## Do not record

Do not paste an incident transcript, credentials, unrelated implementation details, or assume a runtime event from source alone.

## Ownership and verification

Name the owning module and link the applicable contract, source, tests and version. Mark unresolved claims and verification gaps.
