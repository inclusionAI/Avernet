# 会话列表与收藏补全解耦

用户确认：只优化前端，不改后端与 IAM。

## 验收

- 普通会话页返回即展示列表，收藏请求异步补全，不影响 loading、分页、total 或选中会话。
- 收藏状态未知时侧栏及会话顶栏操作不可用；不能把未知状态当成未收藏。
- 收藏筛选继续直接读取收藏接口；完整分页查找保留，不只检查收藏第一页。
- 缓存按登录请求用户、Bot、owner、引擎与运行阶段隔离，实例范围参与页 key；30 秒失效，最多 32 个上下文、每个 8 页，失败不缓存，同页请求合并。
- 收藏写入前后使该上下文缓存失效，晚到的读结果不能覆盖刚完成的写入。
- 用户切换、卸载、范围/搜索代次改变后，不写回过期收藏响应；追加页的补全不丢失其他页。

## 验证

覆盖慢收藏不阻塞列表、失败降级、分页、实例及身份隔离、缓存去重/过期、收藏并发写入和过期响应。

本地验证：`npm run check:open-core`、`npm run ci` 全部通过；711 个测试套件、5800 个测试通过，生产构建成功。未做预发或线上实测。
