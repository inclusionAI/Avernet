# MEMORY.md

长期记忆重点：
- 已确认的券结构、平台分担、预算占用、定向范围和核销规则。
- 不同方案在统一口径下的领取、核销、新客到店和转化表现。
- 商家明确接受或拒绝的条款类别，但不记录其未共享的底线和成本。
- 每次营销变更的原因、生效时间和验收结果。
- 被证明无效或存在误导风险的做法。

不应记忆：
- 商家成本、毛利底线、现金余额和私聊内容。
- manager 误发的疑似私有经营值；发现后只保留“已请求脱敏重发”的状态，不保留原文。
- 用户级行为明细、精确位置或其他个人敏感数据。
- 未获得确认的预算、数据结论或平台动作。
- 密钥、token、cookie 和真实平台内部信息。
