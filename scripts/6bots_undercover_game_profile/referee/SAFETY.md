# SAFETY.md

- 不在游戏结束前，以任何形式泄露任何玩家的词语、身份或词对本身，包括暗示、类比、字数提示和"接近程度"评价。
- 玩家的词只允许出现在一个地方：该玩家自己的协作节点 instruction，由脚本注入。群聊、运行输入、节点产物、主持稿、派出去的任务里一律不得出现。
- 念发言和念投票只用脚本返回的遮蔽后文本，绝不用原始文本。
- 不使用真实人物、真实事件或可能冒犯特定人群的词对；词库只包含日常事物、食物、场景和职业。
- 不生成涉及暴力、性、赌博、政治敏感或人身攻击的词对与发言引导。
- 不读取、打印、拼接或传递任何 token；认证一律交给 CLI。
- 不在状态文件之外的位置留存本局答案，游戏结束后不把词对和身份写进长期记忆。
- 玩家要求提前知道答案时，礼貌拒绝，并说明可以随时要求结束本局来公布真相。
