# 集群执行器平面 —— 容量与成本模型

[English](capacity.md) · 属于[集群执行器平面设计](design.zh-CN.md)

## 1. 每个操作的语句数

| 操作 | 语句数 | 频率 |
| --- | --- | --- |
| 心跳(续期该执行器的全部桶) | 1 次写 | 每节点每秒 |
| 读取花名册 | 1 次读 | 每节点每秒 |
| 认领一个桶(任一结果) | 一个事务内 2 条(条件递增 + 回读) | 只在崩溃后或首次启动时:每个死亡执行器约 4096/N 个,由幸存者分摊;绝不按会话 |
| 围栏步骤 | +1 次对桶行的单行主键带校验 UPDATE(令牌必须匹配;排他锁) | 每个所有者写事务 |
| 转移一个桶 | 1 | 每次排空或再平衡:每个执行器约 4096/N 个 |
| 持久化入站轮次 | 1 | 每轮(先落盘后确认所必需) |
| 所有者拾取回退输入 | **每个执行器每周期**在其桶上做 1 次带索引查询,绝不按会话 | 每个执行器每周期 |
| 故障转移 | 每个幸存者 1 次带索引地读取死亡执行器的桶(约 4096/N 行),然后对每个认领到的桶按每批 2,000 读取其待处理会话 | 每个死亡执行器一次;之后无需再盯 |
| 已转移但尚未采纳的桶 | 每个执行器每个周期 1 次带索引查询(`adopted = FALSE`,最多几百行;通常为空) | 每个执行器每周期 |
| 事件(给 PA 的状态变化) | 不增加语句:Task 记录、`last_event_seq` 和 `unpublished` 在已有的围栏事务内改变;然后 1 次 Stream 追加 | 每次状态变化、中断或步骤结果 —— 每步几次,绝不按 token |
| 重连快照 | **0** 条数据库语句:从会话 Stream 构建 | 每次重连 |
| token(增量) | **0** 条数据库语句。每个 200 ms 批次:在消息队列上,桶的增量频道 1 次发布(网关 → 所有者),会话 Stream 1 次追加(所有者 → 网关) | —(网络与 pub/sub 容量,绝不是存储) |
| 网关 ↔ 执行器消息 | 每轮、每个控制事件、每个派发结果各 1 条 | —(网络,不是存储) |

每一行背后的规则:成本随**节点数和桶数**增长,绝不随**会话数**增长,除非是会话真正在做的
工作 —— 也绝不随 **token 数**增长:token 流量消耗的是网络和 pub/sub 容量,绝不是数据库语句。这些计数应由测试固定下来,使后续改动无法把按节点的查询变成按会话的查询。

## 2. 两种场景

利特尔定律(Little's law):在途会话数 = 到达率 × 平均运行时长。

| | 1 万 API QPS,以读为主 | 每秒 10 万新轮次 |
| --- | --- | --- |
| 在途会话(运行 60 s) | 少 | ~600 万(600 万个会话行;租约仍只有 4,096 行) |
| 数据库语句/秒 | ~1–3 万 | ~100–500 万,以写为主 |
| 新增数据 | 少 | ~1–10 GB/s(每天 ~85–850 TB;假设每轮 10–100 KB) |
| 约束瓶颈 | 无 | 存储写吞吐与数据量 |

在 10 万规模下:OceanBase 且同分区;减少每轮语句数;对入站写做微批;持久化分块或最终输出,而不是每个 token;L3 的保留与压缩变为必需;按压测结果
确定租户规格。这些数字是估算,不是实测。

**步骤缓冲。** 每个在途派发到目前为止的输出会保留两份:派发网关一份(用于拼装结果并交给新
所有者),所有者一份(用于快照)。按每步约 10 KB 计,30 万个并发派发需要所有网关合计约 3 GB、
所有执行器合计约 3 GB。不产生任何存储操作;步骤结果被记录后两份都会丢弃。

**消息队列。** 按 200 ms 一批,每条流每秒向其桶的增量频道发布 5 条增量消息,所有者再向会话 Stream
追加 5 条;30 万条并发流在扇出前约为每秒 300 万次操作(通常每个 Stream 只有一个读者)。按此规模确定
Redis 的容量,或调大批间隔。

**会话 Stream 的内存。** Task 未结束时,一个 Stream 只保留最新快照之后的条目(最多一个步骤的输出,
约 10 KB,外加快照本身),保留期过后就删除。30 万个未结束的 Task 约为几 GB,再加上为法定多数持久性
准备的副本。

## 3. 如何用实测替换估算

1. 在测试中统计每个操作的语句数。
2. 对单节点连真实存储做压测(release 构建),找出拐点。
3. 按实测的语句组合对存储租户做压测。
4. 在负载下杀掉一个执行器,测量再水合的波峰;再杀掉一个网关,测量重连与快照的波峰。
