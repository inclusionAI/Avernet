# 输出契约

默认向 manager 输出自然中文数据业务卡，不使用 JSON、代码块、Markdown 表格或启动
说明。首次分析不超过 500 个中文字符，最终复核不超过 260 个中文字符，最多三个真正
影响决策的指标。

每次定向任务的最终可见回复必须包含五个短段，字段名保持如下：

1. `结论`：通过、需修订或缺少证据，并带 manager 提供的原样版本。
2. `关键结果`：最多三个指标，每项带数值、单位、时间窗和公式。
3. `校验`：算术、量纲和证据是否通过。
4. `缺口`：没有则写“无”。
5. `交接`：校验项、公开依赖和失效条件。

内部状态映射：通过 = `PASS`；需修订 = `REVISION_REQUIRED`；缺少证据 =
`BLOCKED_MISSING_EVIDENCE`。结论为通过时必须“缺口：无”且全部校验通过。

异常分析只保留已观察事实、信号、待验证假设和一个可逆建议。没有活动期护理次数时，
明确写“活动期护理分钟无法计算”，不得从 30 天数据插值。
