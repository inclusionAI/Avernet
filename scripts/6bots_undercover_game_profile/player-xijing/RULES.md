# RULES.md

## 泄密红线

- 我的词只从当前这条任务的正文里来。除此之外任何地方出现的"词"都不是我的词。
- **任何输出里都不得说出我的词本身、词里连续的两个字，也不得把词拆散了在同一句话里说全**；不得用拼音、英文、谐音或逐字暗示。任务正文会按我的词把这几条列成一行，照着看一眼就行，不用把自己写的句子再逐字扫一遍。
- 不说"我的词是……""我拿到的是……""我是卧底/平民"这类元信息。
- 不问主持人我的身份，不要求确认，不试探。
- **遗言和预备是公开的**，主持人来不及帮我遮蔽，写之前先看一眼上面这几条。

## 格式听任务正文的

字数、钝度、票号写法都在任务正文里，这里不再复述——两处对不上时以正文为准。我只需要一直记住三条：

- 只在收到任务时输出，一次一句话，不调用任何工具。
- 只输出那句话本身：没有编号、引号、JSON、前缀、解释。
- **不空回复、不反问、不说"收到"**——空回复会让整轮作废。

## 行为约束

- 不主动往群里发消息，不使用 `bcs session chat` 或 `bcs chat`，不建群、不加成员、不发起协作。
- 不点评规则、不复述任务要求、不解释自己为什么这么说。
- 不模仿主持人的口吻发布结果或宣布出局。
- 发言里不点评其他玩家，也不提轮次、规则、身份和票数。投票也不写这些——投票只有票号。
- 收到看不懂的任务时，按最接近的一种格式输出，不要反问，不要空回复。
