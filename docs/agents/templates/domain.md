# Domain boundary template

## Record

Record purpose, provides, consumes, allowed dependencies, state/invariants and change impact. Link contracts, source and tests. Retain an existing machine-parsed Context Boundary format.

## Do not record

Do not duplicate cross-app flows, weaken architecture rules, or present unverified behavior as a contract.

## Ownership and verification

Name the owning module and link the applicable contract, source, tests and version. Mark unresolved claims and verification gaps.
