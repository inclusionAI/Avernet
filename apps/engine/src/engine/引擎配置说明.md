## 引擎配置说明

### 后端引擎

项目支持两种后端引擎，通过环境变量 `CHAT_ENGINE` 切换（默认 `openclaw`）：

| 引擎 | 版本 | 本地连接地址 | 协议                                                  | 备注 |
|------|------|-------------|-----------------------------------------------------|------|
| **moltis** | dev 分支最新版本 | `127.0.0.1:20001` | WebSocket (需关闭 TLS)                                 | 支持 Chat / Model / Session / Cron |
| **openclaw** | `openclaw@2026.3.12` | `ws://127.0.0.1:18789` | WebSocket，需要在openclaw的config.py中设置你自己openclaw的token | 支持 Chat / Session |



---

### Adaptor 层架构

Adaptor 层是连接上层统一 API 与底层引擎的桥梁，采用 **策略模式 + 工厂方法** 实现引擎无关的业务逻辑。

```
┌──────────────────────────────────────────────────────────┐
│                    API 抽象层 (api/)                      │
│  ChatAPI / SessionAPI / ModelAPI / CronAPI / ...         │
└────────────────────────┬─────────────────────────────────┘
                         │ 实现
          ┌──────────────┼──────────────┐
          ▼                             ▼
┌───────────────────┐         ┌───────────────────┐
│  openclaw/adapter  │         │  moltis/adapter    │
│                   │         │                   │
│  OpenClawChatAPI  │         │  MoltisChatAPI    │
│  OpenClawSession  │         │  MoltisSessionAPI │
│    API            │         │  MoltisModelAPI   │
│                   │         │  MoltisCronAPI    │
└────────┬──────────┘         └────────┬──────────┘
         │                             │
         ▼                             ▼
┌───────────────────┐         ┌───────────────────┐
│  openclaw/client   │         │  moltis/client     │
│  GatewayClient    │         │  GatewayClient    │
│  (challenge握手)   │         │  (token/password) │
└───────────────────┘         └───────────────────┘
         │                             │
         ▼                             ▼
   OpenClaw Gateway             Moltis Gateway
   ws://127.0.0.1:18789        wss://localhost:20001
```

---


### 工厂方法使用

```python
from engine.factory import create_chat_api
from engine.factory import create_session_api

# 使用默认引擎 (由 CHAT_ENGINE 环境变量决定，默认 openclaw)
chat_api = create_chat_api()
session_api = create_session_api()

# 指定引擎
chat_api = create_chat_api("moltis")
session_api = create_session_api("openclaw", gateway_url="ws://10.0.0.1:18789")
```

### 配置说明

#### OpenClaw 配置

| 环境变量 | 默认值 | 说明 |
|---------|--------|------|
| `CHAT_ENGINE` | `openclaw` | 引擎类型选择 |
| `OPENCLAW_GATEWAY_URL` | `ws://127.0.0.1:18789` | Gateway 连接地址 |
| `OPENCLAW_GATEWAY_TOKEN` | (内置默认值) | Gateway 认证 Token |
| `OPENCLAW_CONNECTION_TIMEOUT` | `10` | 连接超时时间（秒） |

#### Moltis 配置

配置加载优先级：环境变量 > `moltis.json` 配置文件 > 默认值

| 环境变量 | 默认值 | 说明 |
|---------|--------|------|
| `MOLTIS_GATEWAY_URL` | `wss://localhost:20001/ws/chat` | Gateway 连接地址 |
| `MOLTIS_GATEWAY_TOKEN` | — | Gateway 认证 Token |
| `MOLTIS_GATEWAY_PASSWORD` | — | Gateway 认证密码 |
| `MOLTIS_CONNECTION_TIMEOUT` | `30` | 连接超时时间（秒） |

### 新增 Adaptor 指南

如需为新引擎添加 Adaptor：

1. 在 `engine/` 下创建新引擎目录（如 `engine/new_engine/`）
2. 实现 `config.py` 定义引擎配置
3. 在 `adapter/` 下实现 `api/` 中对应的抽象接口（`ChatAPI`、`SessionAPI` 等）
4. 在 `client/` 下实现 Gateway 客户端
5. 在 `engine/factory/` 的工厂方法中注册新引擎类型
6. 通过 `CHAT_ENGINE` 环境变量切换到新引擎
