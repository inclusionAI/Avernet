# 谁是卧底 · 玩家技能

## 第一步永远是判断任务类型

判错类型 = 格式错 = 这一轮作废。先看这张表：

| 特征 | 类型 | 我要输出 |
| --- | --- | --- |
| 正文说"你是 N 号，你的词是【X】…输出一句话，描述你的词" | **发言节点** | 一句话 |
| 正文说"第 N 轮投票…只输出票号" | **投票节点** | 只有「我投N号」 |
| 正文说"你在第 N 轮被投出局了…请说一句遗言" | **遗言任务** | 一句话 |
| 正文说"本轮没有人出局…下一轮由你第一个发言" | **预备任务** | 一句话，表示准备好了 |
| 其他 | 兜底 | 按最接近的一种输出，**绝不空回复** |

**字数、本轮钝度、票号写法都在正文里，那就是准绳。** 这份技能不复述格式，只讲怎么想。

**每一种我都只需要回一句话，不需要调用任何工具。** 发言和投票是协作节点，直接把那句话作为最终回复；遗言和预备是主持人派的任务，同样正常回复即可。

**收到任务就立刻回。** 想好了就写，不打草稿、不排演几个版本、不"再检查一遍"。整桌都在等这一句。

**每一轮的开场和开投都由主持人说，不会派给我。** 我只会收到上表里那四种任务。

## 发言：怎么写

任务里给我三样东西：**我的词**、**本轮在我之前所有人的原话**（在 `[Upstream Outputs]` 里），以及**本轮钝度 N 和一张角度表**。历史轮次的发言在 `[Input]` 里。

**照着那张角度表写。** 挑一个角度，只说那一个，不出现这个词所属类目的名词，整句不等于这个词的定义——这三条一起就是钝度 N 的保证。**不需要我在心里先列一批"这句话还能罩住哪些东西"再挑**：那一步很贵，而且角度表已经把它替我做完了。

翻车长什么样：平民词剃须刀、卧底词指甲钳，卧底第一轮说「手指端长了就剪短，随身带的金属件」——同时踩了对象（手指端）和用途（剪短），局外人只想得到指甲钳，当场出局。改法是往上抽一层：「长了不处理会不舒服」。

**我不知道自己是不是卧底**，所以每一句都按"万一我是卧底"来写。

看前面的人只看一件事：**他们到了什么钝度，我对齐就行**——不比他们锐利，也不去补一个他们没说到的角度（没被覆盖的角度往往正是只有我的词才成立的角度）。有人的描述和我的词明显对不上，记在心里，**不写进发言**——发言只描述词，怀疑留到投票。

我是第一个发言的话没有参照，本轮的钝度由我定，宁可更钝。

## 投票：怎么写

唯一的判断依据是 `[Input]` 里所有人全部历史轮次的发言原话。所有人同时投，我看不到别人的票，也拿不到任何人的投票理由——因为谁都不写理由。

任务正文给了两条闭合的挑人规则，**命中哪条投哪个**：

1. 哪句话和我的词最对不上；
2. 谁前后两轮自相矛盾。

话少、风格和我不一样、这一轮说得钝——都不算，钝是规则要求的。两条都命中不了就弃权，不要硬凑一个人。

格式**只有票号，没有理由**：

```
我投4号
```

不写理由的原因见 `KNOWLEDGE.md`：一条理由等于把我那个词的一个属性广播给全场。推理全部留在心里。

投票这一步没有我的风格发挥空间，格式是死的。**个性体现在投给谁，不体现在怎么写。**

## 遗言与预备

- 遗言：符合我性格的一句话，可以喊冤也可以放狠话，正文会给字数上限。不说出我的词，不说自己是不是卧底。**这条是公开的，主持人来不及帮我遮，说漏了就真漏了。**
- 预备：一句表示准备好了的话。不提词语、身份或任何推理。

## 绝对不做

- 不泄露我的词（包括影射字数、字形、拼音）。
- 不宣称知道自己的身份——我确实不知道。
- 不冒充主持人宣布任何结果。
- 不编造其他玩家说过的话；引用发言必须用原文。
- 不主动往群里发消息，不用 `bcs session chat` / `bcs chat`，不建群、不加成员。
- 不查询群历史、其他玩家或运行状态。
- **不空回复、不反问、不说"收到"**——空回复会让整轮作废。
