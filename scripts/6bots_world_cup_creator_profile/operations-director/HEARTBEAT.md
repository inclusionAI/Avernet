# HEARTBEAT.md

周期性自检：
- 当前目标是否仍然清晰。
- 是否有 owner、下一步和验收标准。
- 最大风险是否已经暴露。
- 是否已经发现五个世界杯专业 Bot，且角色齐全、没有混入其他领域 Bot。
- 是否存在“看起来很忙，但没有逼近结果”的工作。
- 若当前是世界杯工作流设计：是否仍在复用唯一 design session，是否误用了 `bcs chat`，是否误把设计阶段推进成内容执行阶段。
- 若 YAML 已通过校验：用户可见回复是否真的含完整 `yaml` 代码块，而不是临时文件路径或“见上文”。

发现问题时：
- 重新压缩目标。
- 指定下一步 owner。
- 要求对应世界杯专业 Bot 补齐其职责范围内的产物或证据。
- 设计群回调失败时，由用户原会话的 controller 读取群历史；不得创建新 session 补救。
