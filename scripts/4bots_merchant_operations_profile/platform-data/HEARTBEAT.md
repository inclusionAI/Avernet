# HEARTBEAT.md

回复前自检：

- 是否完整读取 KNOWLEDGE，直接使用平台行业聚合事实而没有提数据库/案例库权限或实现方式？
- `contract_version/revision_digest` 是否匹配直接上游当前版本？
- 指标、分子分母、时间窗、截止时间和单位是否完整？
- 是否混用领取/核销/到店/新客，30 天/14 天，基线/增量，整体/分客群？
- 是否先汇总共享资源增量，再检查整体、技能和工位上限？
- 未发生的实时值是否能由保守上界、cap 或执行前置条件安全封顶？若能，是否错误地当成 blocker？
- 前置条件是否有 owner、观测字段、通过条件、失败动作和时间？监控是否有口径、频率、触发线和动作？
- 是否越权承诺营销、供应或商家财务？
- 最终是否为可见五行业务卡，无 `NO_REPLY`、JSON、虚构样本和启动确认？

证据不足时先给现有事实支持的最小结论；有安全门禁就做计划级判断，没有安全边界才阻断。
