# TC Card / Doc 迁移边界

**当前 TC 已接入 Card/Doc，默认 legacy 保留旧接口读写旧表，v2 始终读写新表；配置重启后旧接口整体切到新表。**
当前规则以 [完整方案](../../specs/2026-11-04-tc-bcsfuse-card-migration/spec.md)及
[部署步骤](../deploy/tc-card-migration.md)为准，以下原迁移约束与之不一致处由已确认方案取代。

[Card 通用接口](../../packages/search-core/docs/card-management-api.md) 与 [Provider 契约](../../packages/search-core/docs/provider-contracts.md#card-management) 已由 Avernet 提供。
TC 显式挂载接口并提供自己的构建器；不能把其他业务的字段解释、状态规则或推荐编排搬进 TC。

## 复用范围

| 复用 | TC 自己适配 |
| --- | --- |
| Card CRUD、按字段更新、内部版本控制、持久化 | Worker/Profile 输入读取、原 ID 与 Profile 标识兼容 |
| CardDocumentConverter / CardProjection 契约 | TC 正文和前置标签、技能关联和分片映射 |
| Doc 存储、关键词/向量检索及排序基础能力 | recommend 的候选规则与 Fuse 业务流程 |

Card 是完整业务 JSON，没有支付宝字段白名单限制；业务 status/version 等只由 TC 的业务规则解释。
公开可用的数据库/索引适配属于 Avernet；私有平台连接、凭据与部署流程归各宿主。

## 资料对应与兼容要求

| 现有内容 | 迁移要求 |
| --- | --- |
| Worker ID | 保留原 ID，不静默重建外部身份 |
| 名称、描述、能力、技能及扩展资料 | 完整存入业务 Card，不为适配别的业务伪造字段 |
| SOUL、IDENTITY、MEMORY、技能正文等 | 保留 Fuse 所需的原始内容，不能被索引摘要替代 |
| 画像与评估 | 保留内容与输入版本依据；未知版本不能假装最新 |
| Worker config | 独立更新，保留 fusion_enable 等含义与默认关闭融合的行为 |
| 在线状态 | 沿用运行状态机制；频繁状态变更不应触发 Embedding 重算 |
| 可见性、生命周期、信任信息 | 维持各调用路径原规则，不能把离线、私有和删除视为同一状态 |
| 旧 Profile key 和多 Profile 关系 | 先核对存量和请求，不能一律改成 default 或静默丢失关联 |
| 向量与命中片段 | 模型、维度、正文及来源关联可验证时才复用；保留 TC 聚合依据 |

Card 原文、加工画像、业务配置分开更新。检索向量存入 Doc，不能与原文/画像互相替代。
本地修订号控制并发和异步发布，不是需要调用方传入的版本，也不能判断网络迟到的上游事件先后。
同一来源 Doc 成组发布，旧任务不能覆盖新结果，删除标记要能被离线实例恢复时观察到。
业务数据库、命名空间和索引隔离须先约定；仅有 environment 不能防止不同业务的 ID 碰撞。

## 保持现有业务行为

- recommend：保留请求、显式参与者优先、过滤、补充候选、Profile 分片聚合、阈值及返回格式。
- fuse：保留模式、配置检查顺序、上下文选择、提示词、结果缓存与会话存储。
- G9 及其他模式：逐模式验证所需原文和缺失资料容错，不能假设所有模式需要相同字段。
- sync/online/offline：在旧接口仍使用期间保持原请求和应答语义，配置变化正确失效缓存。
- 保存成功和全实例索引生效分开描述，不增加调用方必须先查版本等前置步骤。

## 后续实施与回退

1. 固定旧接口和存量数据基线，核对孤儿记录、多 Profile 关系及未知版本。
2. 实现 TC 构建器、读取/更新适配，先在隔离数据上验证原行为。
3. 迁移全量并追平增量；脚本可重跑，保持同一阶段只有明确的权威写入源。
4. 对照 recommend、各 Fuse 模式、sync 重放/并发、状态限制、缓存失效和模型失败。
5. 在明确的写入窗口切换，验证两实例更新、删除、重启与环境隔离；不长期双主写。

旧库仍为写入源时可退回旧读路径。新库开始写入后，需反向追平或暂停写入恢复，不能只回滚镜像。
保留旧表不等于具备完整回滚方案。功能对齐后才进行匹配数据/模型/缓存条件下的性能评估，
其他业务或合成样本的压测不能作为 TC 迁移容量验收。
