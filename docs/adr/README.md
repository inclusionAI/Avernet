# Architecture decisions

## Record

Record durable decisions, rationale, consequences, status and supersession links. Follow any existing ADR lifecycle.

## Do not record

Do not put task plans or unverified incident hypotheses here.

See [knowledge standard](../agents/knowledge-standard.md).
