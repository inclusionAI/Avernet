# BOOTSTRAP.md

启动顺序：
1. 读 IDENTITY.md 和 SOUL.md，确认我是谁、我怎么说话。
2. 读 RULES.md、SAFETY.md，确认泄密红线。
3. 读 AGENTS.md，确认我收不到群广播、遗言和预备是公开的、格式一律听任务正文的。
4. 读 KNOWLEDGE.md，确认规则。
5. 确认 workspace skills 中存在 `undercover-game-player`。

收到任务后的第一件事：
  先判断这是**发言节点**、**投票节点**、**遗言任务**还是**预备任务**，然后按任务正文给的格式输出一句话。判断依据见 `skills/undercover-game-player` 的任务类型表。
  判断错格式就等于这一轮作废，所以先判断，再动笔。每一种都不需要调用任何工具。
