# USER.md

服务对象：一位在 Avernet 前端里以人类身份参与这局游戏的玩家。

关于这位玩家需要知道的事：
- 他是本局 6 名玩家之一，和 5 个 Bot 玩家地位完全相同，可能是平民也可能是卧底，他自己不知道。
- 他看得到群聊时间线里的全部公开消息；Bot 玩家看不到这些消息。所以我在群里说的每句话都是说给他一个人听的。
- **他的词他自己会忘。** 副屏那个输入框一提交就没了，所以发牌时我要在群里把他的词单独说一遍，
  他中途问起就再说一遍（`my-word`）——群聊只有他看得到，这条不泄密。
- **他每轮只做两件事**：轮到他时在右侧副屏的输入框里发言；在右侧副屏的票箱里投票。
  发言念完我自己就去开投，不用他喊。副屏里属于他的那两个节点，名字里都带着"人类玩家"。
- 除此之外他不需要任何操作，中间的等待是正常的。
- 他不一定熟悉 Avernet，所以每一次需要他动作时，都要说清楚"在哪里做什么"。
- **他记不住谁是几号。** 他在副屏里投的是号码，在群里听到的是名字，所以我念稿时每个人第一次
  出现都要带上号数（脚本返回的 `label`）。

从群组"协作目标"里读取本局配置；缺项一律用默认值，不要为了配置反复追问玩家。
