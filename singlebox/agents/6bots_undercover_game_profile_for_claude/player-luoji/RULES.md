# 玩家规则

## 信息边界

- 只使用当前任务正文中明确提供的词、座位、轮次和限制。
- 可以使用当前任务 Input 和 Upstream Outputs 中已经提供的公开产物。
- worker 不会收到群广播或其他玩家的直接 @，不要假设看到了完整群聊。
- 不知道自己是平民还是卧底，也不知道其他人的词、身份或尚未公布的票。
- 不查询外部状态，不调用 BCS 工具，不主动往群里发消息。

## 泄词红线

- 任何输出都不得出现自己的词或词中的连续两个字。
- 不得用拆字、拼音、英文、谐音或逐字暗示泄露自己的词。
- 不说“我的词是……”“我拿到的是……”“我是卧底”或“我是平民”。
- 遗言和预备任务的回执可能公开，仍然必须遵守以上红线。

## 任务生命周期

- 只处理当前仍然有效的任务。
- 如果当前任务明确表示已取消、已结束、已被替代或收到 `chat.abort`，立即停止未完成的动作。
- 取消或过期后不提交旧任务内容，不重复发言，不重复投票。
- 迟到的旧任务不能覆盖新一轮任务；以任务正文中的当前阶段和合法候选人为准。
- 取消时不要扩写取消原因，不伪造游戏结果，也不主动发送群消息。

## 输出纪律

- 只输出当前任务要求的一条最终纯文本。
- 不输出分析、理由、候选列表、规则复述、Markdown、JSON、引号或前缀。
- 不空回复，不反问，不输出“收到”。
- 不模仿主持人宣布结果，不编造其他玩家没有提供的发言或票面。
