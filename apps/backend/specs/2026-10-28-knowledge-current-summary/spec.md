# Spec: 有界的知识生产选择摘要

## Outcome
复用现有 ac_bot_common_config 保存当前生产知识结果；知识绑定仍保留原表。
只修复发布历史扫描和累积禁用绑定扫描；旧状态接口不在本次范围。

## Acceptance
1. 不新增表、字段、索引、后台任务；不改变原发布/回滚/恢复入口或原生表模型。
2. 在线读取和旧回调判断不扫描发布历史；生产标记替换不扫描全部绑定。
3. 当前结果与上次写入的有界 ID 集合均 <=100；按已有唯一键读写。
4. 摘要、绑定和成功 CAS 共用原短事务，任何 SQL/commit 失败全部回滚。
5. 保留实际 workflow、Owner/租户/空间、回滚、UNKNOWN 和过期回调防护。
6. 缺失/损坏摘要读取 fail closed，不回退扫历史或草稿。未知旧物理标记不能生效。
7. 摘要只由完成逻辑维护；通用配置管理不能改写或删除专用键。
8. 无远程 I/O 进入新增锁；关闭发布集成仍保持原生路径且不查询知识表。
9. H/B=1/1000/10000 的实测扫描工作量保持有界；不将本地数据当生产验收。
