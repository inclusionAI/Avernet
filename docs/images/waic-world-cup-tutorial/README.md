# WAIC 世界杯教程截图清单

这些 SVG 是教程的截图占位文件。补图时优先保持相同画幅；如果改用更常见的 PNG，请沿用文件主名，并同步把教程链接的扩展名改为 .png。

| 文件 | 需要截取的画面 | 脱敏与裁剪要求 |
| --- | --- | --- |
| 01-prerequisites-terminal.svg | macOS 打开终端，git --version 成功 | 隐藏真实用户名、主机名和私人目录 |
| 02-install-tools-complete.svg | install-tools 完成和关键工具检查通过 | 不显示私有 registry、代理或 token |
| 03-model-config-choice.svg | 三种模型配置选择提示 | 不截取 .env.local 内容或 API Key |
| 04-stack-ready.svg | bcs_frontend 启动完成或状态页 | 保留 8000、21000 和 Running 状态 |
| 05-six-bots.svg | 6 个 Bot 的 status 输出 | bot_uuid 可打码，保留 Bot 名称和 Running |
| 06-enter-avernet.svg | Avernet 首页入口和顶部“世界杯运营总监”视角 | 不显示私人浏览器书签或账号信息 |
| 07-custom-collaboration-template.svg | “自定义协作”、模板选择、“世界杯比赛前瞻内容生产”和校验结果 | 保留真实按钮文案和“已解析 6 个角色” |
| 08-role-bindings.svg | 6 个 participant 与 6 个 Bot 绑定完成 | bot_uuid 不需要出现 |
| 09-new-session.svg | “新建会话”弹窗与演示输入 | 使用教程中的虚构比赛，不放未发布真实选题 |
| 10-running-and-result.svg | 节点运行状态与最终发布包 | 不显示模型 API、内部地址或未授权内容 |

推荐截图宽度至少 1440 像素，浏览器缩放保持 100%。如果一张图无法同时看清节点图和最终内容，可以把第 10 张拆成 10a、10b，并在教程中各加一个链接。
