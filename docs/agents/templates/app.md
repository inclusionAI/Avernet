# App README template

## Record

Record the app purpose and boundary, provided interfaces and dependencies, source and domain navigation, assembly and version sources, important flows and diagnostics, and development and verification. Link existing contracts and tests.

## Do not record

Do not copy domain internals, speculative ownership, secrets, runtime data, or complete change specs.

## Ownership and verification

Name the owning module and link the applicable contract, source, tests and version. Mark unresolved claims and verification gaps.
