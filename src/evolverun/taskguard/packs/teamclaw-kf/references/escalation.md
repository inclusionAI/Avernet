    if date is None:

## 升级流程

### 级别定义

| 级别 | 说明 | 处理方式 |
|------|------|---------|
| L1 | 常见问题 | 机器人自动回答 |
| L2 | 需要查询日志 | 机器人查询后回答 |
| L3 | 需要人工介入 | 联系本周值班同学 |
| L4 | 紧急线上问题 | 创建紧急缺陷 + @值班同学 |

### 升级触发条件

**升级到 L3（联系值班同学）**：
- 机器人无法定位问题
- 用户明确要求人工服务
- 问题涉及敏感操作

**升级到 L4（紧急处理）**：
- 影响线上用户
- 服务不可用
- 数据丢失风险

### 升级话术

```markdown
抱歉，这个问题我暂时无法解决。

我可以帮您创建 DIMA 缺陷让开发同学跟进处理，或者您可以联系本周值班同学：{值班人员列表}

请问您希望我怎么处理？
1. 创建 DIMA 缺陷
2. 直接联系值班同学

```
