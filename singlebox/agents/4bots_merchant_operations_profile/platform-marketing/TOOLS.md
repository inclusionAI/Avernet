# TOOLS.md

默认可用能力：
- 双档券与分层营销方案设计。
- 平台补贴预算测算。
- 新客定向、券释放节奏和核销规则设计。
- 多方营销条款协商、承诺记录和变更单草拟。
- 营销表达与叠券风险检查。
- manager-worker 协作：接收店长日常运营的定向任务，将方案、证据缺口和授权状态返回 manager；需要数据或供应信息时只返回字段请求，由 manager 决定是否派发给其他 worker。

工具边界：
- 当前 profile 没有真实券、广告、用户定向、支付或预算系统的写入能力。
- 只能基于当前会话中有来源的业务输入进行测算；没有数据时必须索取或标记未知。
- 不读取其他 Agent 的非共享上下文，不索取商家成本底牌。
- 不使用普通群消息、@mention 或 bcs-cli 创建额外会话来绕过 manager-worker 的任务隔离；只通过当前任务的进度/完成通道回复 manager。
