# Avernet HTML Keynote

**当产品开始替用户组队：AI 运营从单点智能走向协作交付**

直接用现代浏览器打开 `index.html`。该文件已内嵌样式、脚本、Avernet 标志和截图，复制单个 HTML 文件即可离线演示。面向产品、设计听众，共 33 页主讲、1 页致谢与问答和 5 页技术附录；主讲时间分配合计 50 分钟，问答与附录另计。

讲述顺序：目标与协作（9 分钟）→ 小店经营（10 分钟）→ 谁是卧底（7 分钟）→ 上下文与能力设计（7.5 分钟）→ 协作体验设计（8.5 分钟）→ 设计检查表（1.5 分钟）→ 亲手体验（2 分钟）→ 产品增长（4.5 分钟）。

第 26–28 页依次讨论目标与授权、进度与决策、人的介入与决定，使用标明来源的交互设计示意。第 30 页保留“5 分钟部署 Avernet”标题和两条启动命令，主讲用 2 分钟介绍上手入口；页面明确说明“5 分钟”为上手引导，非安装耗时保证，首次下载与编译可能更久。第 33 页总结后，第 34 页“谢谢，欢迎交流”作为附录前的致谢与问答页，展示交流主题、项目与示例入口；查看附录后可回到本页。第 35–39 页保留详细安装、场景 profile、Singlebox、微服务与架构边界，问答中可按 O 从总览选择。

## 演示操作

| 按键 | 操作 |
| --- | --- |
| 左右键、Page Up / Down | 翻页 |
| 空格 | 下一页 |
| Home / End | 第一页 / 最后一页 |
| F | 全屏 |
| O | 总览并跳转 |
| N | 打开独立讲者窗口 |
| B | 黑屏，再按任意键恢复 |
| P | 打印全部幻灯片，可选择另存为 PDF |
| ? | 快捷键帮助 |

触屏可左右滑动。鼠标静止时底部工具栏自动隐藏，移动鼠标即可恢复。

讲者窗口显示当前页、下一页标题、逐页备注、来源与建议时间。将演示主窗口放到投影屏，将讲者窗口保留在自己的屏幕。点击“开始计时”后计算实际用时，支持暂停和重置。浏览器需要允许弹窗；关闭后可按 N 重开。

## 修改内容

- `deck-content.js`：逐页内容、备注、来源和时长。
- `theme.css`：16:9 演示版式与配色。
- `runtime.js`：翻页、讲者视图、计时与交互。
- `shell.html`：HTML 外壳。
- `build.py`：将上述文件、图标与截图打包为单文件 HTML。
- `assets/undercover-game.png`：真实游戏副屏组件的演示数据截图，仅保留房间区域。
- `assets/shop-team-roster.png`：周年庆协作群截图的公开裁剪版，第 10 页展示成员与人类加入入口。
- `assets/shop-review-workflow.png`：历史 Demo 合成截图中提取的复核流程片段，第 13 页展示三方复核、店长汇总与等待店主验收。
- `assets/shop-owner-acceptance.png`：店主验收截图的公开裁剪版，第 14 页展示审核说明、意见输入与提交入口，移除了截止时间行和下方运行日志。

小店截图来自作者提供的历史 Demo，流程片段取自流程与验收合成图的左侧。三方节点显示完成不等于经营约束均已通过；第 13、14 页的店主验收仍待处理，不能据此认定方案通过验收或外部业务执行完成。游戏截图来自 `src/bcs/assets/panel/test/undercover-game/visual-preview.html?mode=bubbles&width=760&height=1000`，由真实游戏副屏组件和仓库演示数据渲染，不代表在线模型对局。Avernet 图标与字标复用 `src/frontend/public/` 中的原始素材。

`assets/` 仅保留经过像素裁剪的公开版截图，已移除浏览器界面、地址、会话及工作流 ID、无关日志和截图元数据。验收图另移除截止时间行，其余保留区域的文字、数值和状态保持原样。完整原图与备用合成图不存放在本目录。构建脚本只嵌入这四张公开截图及 Avernet 标志，不再从教程目录嵌入完整截图。逐页备注与来源随 HTML 一同公开。
