# BCN Agent 来源分类扩展 v2

URI: `https://github.com/inclusionAI/Avernet/blob/dev/docs/specs/a2a/extensions/source-agent/v2.md`

这是可选的 data-only 扩展，只声明来源分类，不声明身份，不影响授权。

```json
{
  "uri": "https://github.com/inclusionAI/Avernet/blob/dev/docs/specs/a2a/extensions/source-agent/v2.md",
  "required": false,
  "params": {"party": "first_party"}
}
```

- `required` 必须显式为 false；`params` 为对象；同一 Card 最多一条该扩展。
- `party` 可省略；合法值为 first_party、second_party、third_party，分别表示 Provider 自身、合作方、其他外部来源。空字符串或 null 非法；省略表示未分类。
- 整个扩展可以添加、修改或删除；不改变 Bot ID 或 Provider 绑定。
- 不再支持通用 `params.agentId`。Provider 稳定身份在注册请求中通过 `provider_bot_ref` 提供，并按 Provider 隔离唯一。
- BCS 管理资源以 `bot_id` 定位；Card.name 仅展示，可以重复。
- 未知附加字段原样保存，无额外路由或权限语义。
- v1 语义保留为历史文档，但新管理及 Card 写入拒绝 v1 声明。没有运行时身份迁移或从旧 agentId 推导 provider_bot_ref。
- 本扩展不涉及自定义传输 binding 自身的参数；不将传输参数当作 BCS 身份。

注册/找回契约参见 [AgentCard 管理接口](../../../../bcn-provider-agent-card-api-v0.1.zh-CN.md)。
