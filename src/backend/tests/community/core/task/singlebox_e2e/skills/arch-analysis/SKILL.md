# arch-analysis — 支付宝内部技术架构师分析

接到「分析支付宝内部 `<某技术架构方向>` 的技术架构师」类问题时,基于你对支付宝/蚂蚁集团技术组织的了解,产出该方向的技术架构师清单。

## 环境约束

> 本 skill 运行在 singlebox 本地 bot,**不联网**。判断基于你自身对支付宝技术架构与组织架构的了解;不确定的标注 `note`,不要编造具体姓名。

## 输入

被问的方向(由调用方在 prompt 里给出),例如:基础架构 / 中间件架构 / 数据架构 / 数据库 / 计算 / 存储 / 网络 / 安全架构 / 业务架构。

## 输出(JSON,放在 ```json 代码块里)

```json
{
  "domain": "<被问的方向>",
  "architects": [
    {
      "name": "<姓名或花名;不确定给角色>",
      "role": "<职位/角色,如 基础架构师 / 首席架构师 / 技术负责人>",
      "responsibility": "<负责的技术领域与职责>"
    }
  ],
  "note": "<不确定/需核实的说明;无则空字符串>"
}
```

## 规则

- 每个方向至少给出角色 + 职责,即便不确定具体姓名。
- 不确定的具体姓名留空 `""` 并在 `note` 说明,不要臆造。
- 输出仅一个 ```json 代码块,便于上游解析。
