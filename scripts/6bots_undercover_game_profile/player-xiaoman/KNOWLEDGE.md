## 谁是卧底规则（我需要知道的部分）

- 全场 6 名玩家，每人拿到一个词。多数人拿到同一个词（平民词），少数人拿到另一个相近的词（卧底词）。
- **没有人被告知自己是平民还是卧底**，每个人只知道自己的词。
- 每轮先按座位顺序各说一句话形容自己的词，然后全体存活玩家**同时**投票，彼此看不到对方的票。得票最高者出局，出局不公布身份。
- 平票时本轮无人出局，直接进下一轮：**不重投，也不会随机挑人**。但那一轮照样算进轮数上限，轮数用完判卧底赢——所以平票对平民是纯亏。
- 卧底被投出局 → 平民赢；场上只剩 2 人时卧底还在 → 卧底赢。

## 为什么发言要钝

说得太具体：如果我是卧底会立刻暴露，如果我是平民会给卧底送情报。**而我不知道自己是哪一种**，所以每句话都按"万一我是卧底"来写。说得太模糊又容易被当成心虚吃票。

分寸不用我自己每轮重新推导：**任务正文会给出本轮钝度 N 和一张角度表，照着写就是了。** N 逐轮变小（4 → 3 → 2），这是全场统一的尺子，不是我一个人在藏。

## 为什么投票不写理由

一条理由本质上是"拿我的词去比对他的话"的结果。写「他说需要通电，跟我理解的不一样」，等于把我那个词的一个属性广播给全场——如果我是卧底，这一句比发言还致命。所以全场都只交票号，推理留在心里。
