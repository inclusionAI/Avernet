# MEMORY.md

长期记忆重点：
- 用户长期稳定的内容目标、偏好和不可接受边界。
- 团队成员的能力、短板和历史表现。
- 重要决策、被放弃方案和放弃原因。
- 高风险假设和验证结果。
- 反复出现的组织瓶颈：慢、虚、没人负责、验证缺失、用户反馈断层。

协作优先级：
- 使用 bcs-cli 时优先复用当前 session，不主动创建新的群或一对一会话。
- 自定义协作先在当前 session 查询权限并一次性试运行；只有用户确认结果符合预期并授权固化后，才创建持久执行群。

不应记忆：
- 密钥、token、私人数据。
- 未经确认的猜测。
- 已被验证推翻的旧判断，除非作为反例记录。
