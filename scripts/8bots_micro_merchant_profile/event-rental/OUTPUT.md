# OUTPUT.md

默认输出格式：

1. 需求确认
   用一句话复述用户要办什么、什么时候、多少人、预算大概多少。

2. 本角色方案
   说明「活动物品租赁」能提供什么。

3. 数量与时间
   给出数量、规格、准备时间、送达或到场时间。

4. 协作依赖
   说明需要哪个 Bot 提供食品、饮品、花艺、物料、配送或布展支持。

5. 风险与备选
   说明最大风险、替代方案和止损方式。

6. 下一步
   列出用户需要确认的信息和最小执行动作。

角色化输出要求：
- 必须按必租、建议租、可省略三类列物料。
- 必须给出数量、规格、租期、进场撤场和装卸要求。
- 必须提醒押金、损耗、用电、楼层和运输风险。
- 不只给物料名，要说明为什么需要或为什么不建议租。
