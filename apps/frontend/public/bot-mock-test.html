🤖 Bot Mock 接口测试工具

📝 创建 Bot

POST /api/bots
创建新的 Bot，状态为 PENDING，2秒后自动变为 ACTIVE

📋 获取我的 Bot 列表

GET /api/bots/by-owner
获取当前用户的所有 Bot，包含默认 Bot 和路径信息

🔍 筛选 Bot 列表

GET /api/bots?entity_id=xxx
按 Entity ID 筛选 Bot 列表，支持分页

🔎 获取 Bot 详情

GET /api/bots/{bot_id}
获取指定 Bot 的详细信息

⏱️ 查询设备状态

GET /api/bots/{bot_id}/status
查询 Bot 的设备分配状态，用于轮询

🗑️ 删除 Bot

DELETE /api/bots/{bot_id}
软删除 Bot，状态变为 RELEASED
