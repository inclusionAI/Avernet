## 回环协议测试

在示例目录执行 README 中的 unittest 命令。WebSocket 走真实客户端和回环服务端，使用可控的模型结果复现取消和断线。

- 错误会话的取消返回 SCOPE_MISMATCH。正确会话收到一个 aborted 事件。随后新任务正常完成，旧推理晚于新任务返回时没有新的 final。
- 同一 run 在重新建立 WebSocket 后被重发时，玩家再次 ACK，但没有第二次推理或投票。测试同时验证下一项新任务正常完成。
- 同时收到群展示文本和原始任务时，SDK 只收到原始任务。缺少原始任务字段时继续使用消息正文。
- 使用实际 Agents SDK 和本地 Responses 测试端点验证非法投票的单次纠正。请求不启用响应存储。

## 更新版真实 BCN 复验

升级后重新连入原版 BCS，使用已有牌桌的主持人身份绑定两个合成任务。两个节点均完成。原版裁判判定 16 字发言无违规，投票结果为「我投1号」。复验使用原版 BCN 适配器和本机已配置的模型网关。同一原版环境另开会话发送一次「开始」后，主持人回了消息，第一轮游戏状态机仍未派发。完整对局的统计来自上面的三局。 [测试定义](evidence/live-bcn.yaml) · [BCS 回执摘要](evidence/live-bcn.json)
