# 谁是卧底游戏领域

本词汇表定义谁是卧底游戏中的参与身份，以及游戏与承载会话的边界。

## 参与者与游戏局

**游戏局（Game）**:
从锁定参赛名单、分配词语到判定胜负的一次完整游戏。开局后的参赛名单固定。
_避免使用_: 用“会话成员”直接表示本局玩家

**玩家（Player）**:
被列入本局参赛名单、获得座位与词语并参与胜负判定的参与者，包括 Human 玩家和玩家 Bot。
_避免使用_: 将主持人计入玩家人数

**Human 玩家（Human Player）**:
由真人以自己的身份参与本局的玩家，其词语在终局前属于该玩家的私有信息。
_避免使用_: 用单一“人类玩家”身份合并多个真人

**玩家 Bot（Player Bot）**:
以独立玩家身份参与本局的 Bot，与 Human 玩家遵守相同的阵营和胜负规则。
_避免使用_: 主持人、会话内任意 Bot

**主持人 Bot（Referee Bot）**:
负责组织游戏、发词与裁决的非参赛 Bot，不占玩家座位、不参与投票或阵营胜负。
_避免使用_: 玩家 Bot
