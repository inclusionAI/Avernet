# ClawInsight Skills

本目录是 Avernet 内治理、验收技能的维护入口，与 `clawevolve-skills` 同级。
仅维护两个业务分析职责；不依赖个人技能仓库，不复制旧评分程序，不引入独立调度器。

- `clawweb-governance/`：根据程序提供的数量榜和证据，生成结构化治理提案。
- `clawweb-verification/`：对照原问题与修复后执行证据，解释程序生成的验收结论。

## 运行隔离约定

复用已有 AIS 公共入口，不覆盖公共入口、其他任务的配置或当前已发布任务。
治理/验收需要独立的任务定义、配置文件、任务包标识、产物目录和状态目录。
正式工作根目录约定为部署提供的工作区；不在技能中固定某个 AIStudio 节点 ID。
所有生产主机、ODPS项目、NAS路径、模型连接、凭据通过独立部署配置提供。

对于已经授权并发布的正式治理任务，运行一次应自动提交合格候选到效果中心待审批，
不在进程中等待对话确认。管理员后续在效果中心审批、驳回及推送用户。
`dry-run` 是明确选择的联调模式，不是人工审核前额外执行的一道生产步骤。
这条约定不授权交互式分析任务自行开启正式写入或发布调度。

## 当前接入状态

本目录此次落地的是项目内 Skill、输入输出协议和验证测试。
机械程序位于同级的 `clawweb-governance-batch`，通过其 `scripts/run.sh` 接入已有公共 `main_ais.py`；
它不会覆盖公共入口，也不读取或修改其他任务的配置。该包的任务输入通过 `batchConfigPath` 指向独立配置，
由公共执行器传入独立的任务产物和状态目录。

本目录只维护治理、验收两个 Skill 的说明、输入输出协议和可移植测试；运行实现不复制到两个 Skill 中。
调度时间由 AIStudio/Dataphin 的任务定义决定，不在仓库里新增调度器。
批处理包内置跨运行观察缓存、根因级去重和驳回冷却，并兼容读取旧 `nightly-v1:` 根因标识。

## 安全与验证

- 模型只输出结构化分析；没有 Shell、挂载、配置写入、审批或通知权限。
- 数据取证、数量、根因签名、去重、请求校验、提交和验收门禁由程序执行。
- NAS 每次启动确认只读；分析阶段不得挂载、重挂载或写入 Bot 工作目录。
- 缺数据、权限失败、模型输出错误不能伪装成“本次没有问题”。
- 两个 Skill 不包含凭据、私有主机、机器绝对路径或生产默认地址。

验证：在本目录运行 `python3 -m unittest discover -s tests -v`。
技能 frontmatter 和 UI 元数据还应通过 Skill Creator 的规范校验。
