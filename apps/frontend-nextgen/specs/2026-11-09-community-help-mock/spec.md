## 产品边界

在现有社区页保留原「求助」，新增「求助\_new」独立页签。初始包含「全图风控AiCoding」
和「TC-AiCoding」两个模版，默认选中前者；原有四条示例任务仍属于前者，后者初始为空，
可独立配置团队、来源和创建任务。可新增多个命名模版，模版类型暂仅支持 AiCoding。模版配置包括说明、多个
Mock Bot、每个 Bot 的一个或多个角色（需求采集、架构、应用、代码、verify、pr），
以及启用的任务来源（Dima、Task Discover、手动输入）。启用 Dima 时必须配置项目空间（名称或 ID）；
启用 Task Discover 时必须在单一「Task Discover Bot」字段填写发现任务的 Bot 名称，不再单独填写或展示 Bot ID。发现 Bot 独立于协作团队，不限定为圈选的 Mock Bot。
未启用的来源无需填写详情；切换启用状态保留表单草稿，取消不保存。新增及设置模版均可选择「指定 Bot」或「开放」：
默认仍为指定 Bot；开放不绑定固定成员、不等同于全选当前 Mock Bot，无需圈选或分配到特定 Bot，
按需求采集、架构、应用、代码、verify、pr 六角色演示协作。切换范围保留未保存的圈选草稿，
取消不生效；保存开放模版时清空固定成员，重新打开后不保留隐藏的 Bot 限制。

创建任务必须填写标题、说明及当前模版启用的来源，外部来源可填写任务编号。
Dima / Task Discover 任务使用并展示模版中配置的项目空间 / Bot 信息。手动输入不需要来源编号，
可勾选「自动同步到 Dima 项目」，此时必须填写目标项目空间，默认带入模版的 Dima 项目空间且允许修改。
仅启用手动输入的模版也能配置同步目标，无需启用 Dima 作为入站来源。取消勾选或切换来源清除同步意愿，
非手动来源不允许开启该选项；保存未勾选任务时目标归一化为空。自动同步仅保存意愿与目标，
在界面展示「模拟待同步（未实际同步）」，不调用 Dima、不生成外部任务编号，不因模拟推进变为真实同步成功。
任务保存创建时的协作范围、成员、角色和来源快照；后续模版配置不追溯修改已有任务。
任务侧屏借鉴 TaskPanel 展示，不挂载会轮询真实服务的 TaskPanelFetcher。
支持查看阶段详情、执行动态、产物及显式「模拟推进」；没有真实派发、PR、上传或外链。
每个模版的任务区默认使用现有卡片视图，可切换为列表视图。两种视图共用状态、来源、搜索、
任务顺序、空态和任务侧屏；切换展示方式不重置筛选或修改任务。列表展示标题、说明摘要、
来源与编号、状态、阶段进度、当前阶段及负责 Bot，支持通过标题或操作入口打开副屏。
视图选择只属于当前工作台的 UI 状态，切换模版或筛选时保留，不新增持久化。

Mock 状态仅保存在内存，切换页签保留，浏览器刷新恢复初始数据。界面明确提示此边界。

## 验收条件

1. 当用户点击「求助\_new」，社区应展示 Mock 协作工作台；切回其他页签仍展示既有列表，且不把新页签作为 topic_type 发送。
2. 当首次进入，系统应展示「全图风控AiCoding」和「TC-AiCoding」两个模版，默认选中前者并保留涵盖进行中、待处理、需关注、已完成状态的四条示例任务；切换至后者时初始无任务，新建任务仅属于当前模版。
3. 当用户新增或设置模版，系统应允许圈选多个 Bot 和各自多个角色，保存后立即展示结果；取消不改变数据。
4. 当模版名称空白、名称重复、指定 Bot 模式下没有 Bot 或选中 Bot 没有角色、或没有启用来源时，系统应拒绝保存并显示可理解的错误。
5. 当用户创建任务，系统应只允许当前模版启用的来源；标题或说明空白时拒绝保存。
6. 当任务创建成功，系统应将任务加入当前模版，初始化与配置角色对应的有序协作阶段，清除列表筛选并打开任务侧屏。
7. 当用户修改模版配置，已有任务应保留创建时的角色和来源快照；新任务使用新配置。
8. 当用户切换模版、来源、状态或搜索词，系统应只展示对应任务，并对空结果提供清除筛选入口。
9. 当用户打开任务，侧屏应展示状态、阶段完成比例、各阶段负责 Bot 和结果、执行动态以及示例交付产物。
10. 当用户点击「模拟推进」，系统应推进一个阶段并同步列表与侧屏；需关注任务应先恢复执行；完成后进度为 100%，不可再推进。
11. 当用户取消新建、关闭侧屏或切回原求助页签，系统应不创建任务、不触发任何真实任务/Bot/来源接口。
12. 当屏幕较窄，模版列表、筛选、任务卡片应换行，任务列表仅在自身容器内横向滚动，侧屏及配置弹窗不超出视口；控件有可访问名称且可键盘操作。
13. 当进入任一模版，系统应允许在卡片视图和列表视图间切换，默认卡片视图；两种方式展示相同任务及状态、进度，切换不改变数据、顺序或现有状态/来源/搜索条件。
14. 当使用任一视图切换全部任务、待处理、协作中、需关注、已完成，系统应展示相同筛选结果；空模版或无匹配结果仍可切换视图，清除筛选应保留视图选择。
15. 当从列表点击任务标题或查看进度，系统应打开相同任务副屏；模拟推进后列表和卡片应展示同一最新状态及进度。
16. 当切换至其他已有或新增模版，系统应保留当前视图选择，且只展示当前模版的任务。
17. 当新增或设置模版选择「开放」，系统应允许不圈选任何 Bot 保存；指定 Bot 模式仍校验 Bot 和角色，名称与来源的校验在两种范围均生效。
18. 当在开放与指定 Bot 之间切换未保存的草稿，系统应保留草稿中的圈选及角色；取消不改变已保存模版，保存开放配置后固定成员为空，再打开仍展示开放。
19. 当开放模版创建任务，系统应建立六角色阶段而不预先绑定任何 Bot；模版摘要、创建说明、卡片、列表、侧屏与产物应明确开放协作，不展示虚构的 Bot 名称或「0 个 Bot」误导计数。
20. 当开放任务模拟推进，系统应正常更新进度、产物并最终完成；后续模版切换协作范围不改变旧任务的协作范围快照。

21. 当新增或编辑模版启用 Dima / Task Discover，系统应分别要求非空项目空间 / Bot 名称（单一「Task Discover Bot」字段），开放协作也不能绕过此校验；未启用的来源不要求详情。
22. 当编辑、切换来源启用状态、取消或重新打开模版设置，系统应保留当前未保存草稿，取消不写入；保存后重新打开应回显已规范化的详情，不修改其他模版。
23. 当从 Dima / Task Discover 创建任务，系统应展示并复制创建时的项目空间 / Bot 名称，Task Discover 不展示 Bot ID；后续修改模版不改变旧任务详情。
24. 当选择手动输入，系统应允许直接填写标题及说明，不要求外部编号；可选自动同步到 Dima，未勾选时不保存同步目标。
25. 当手动输入勾选自动同步，系统应允许填写或修改目标项目空间，并要求非空；默认带入已配置空间，即使 Dima 入站来源未启用也可手动指定目标。
26. 当取消勾选或从手动输入切换到其他来源，系统应清除同步意愿，不丢失标题与说明；非手动来源携带同步意愿时领域层应明确拒绝。
27. 当任务创建或模拟推进，卡片、列表与任务副屏应展示来源详情和手动任务的同步目标 / 模拟待同步状态；筛选支持手动输入，不产生真实同步成功、真实请求或虚构 Dima 编号。

28. 当新增或设置模版配置 Task Discover，系统应只提供一个必填的「Task Discover Bot」输入，不再提供独立的 ID 与名称输入；保存时去除名称首尾空白，禁用来源无需填写。新建任务预览、卡片、列表及副屏均只展示来源 Bot 名称；编辑模版名称不改变旧任务快照。
