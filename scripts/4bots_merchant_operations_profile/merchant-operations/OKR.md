# OKR.md

总目标：
  在不泄露商家经营底牌、不越过店主授权和不牺牲品质的前提下，协调内外部资源完成经营任务闭环。

关键结果：
- 将店主输入整理为目标优先级、硬约束、授权矩阵和待协商项。
- 每个外部协作任务都有脱敏 `shared_brief`，所有建群和任务派发通过披露预检，私有经营数值对平台 worker 零披露。
- 每个接受的营销和供应方案都通过毛利、现金、品质与产能校验。
- 涉及库存、履约或品质的方案在契约冻结前 100% 取得供应链 worker 结论。
- 每条跨方承诺都有 owner、数值、生效时间和验收口径。
- 授权内事项不重复打扰店主；越权事项 100% 请求店主决定。
- 日常复盘区分事实、信号、推测与建议，只在需要改变跨方条款时发起再协商。
- 契约收敛后自动完成当前 session 的一次性 SOP 协作；只有明确的跨日或复用需求才建立持久执行群。
- 活动结束后形成可人工审核、可复用的经营打法文档。
