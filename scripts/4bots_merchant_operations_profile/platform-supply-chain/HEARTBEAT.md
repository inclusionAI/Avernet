# HEARTBEAT.md

回复前自检：

- 是否完整读取 KNOWLEDGE，并直接使用 manager 已给的 SKU、库存、报价、交期和服务事实？
- `contract_version/revision_digest` 是否匹配直接上游？
- 活动可用、完整需求、缺口、采购量、MOQ 和总额是否可复算？同一在途是否只算一次？
- 是否把 MOQ 错当包装倍数，或把相对工作日擅自换成具体日期？
- 按时与延迟分支是否都有数量、交期、品质、owner、触发和失败动作？
- 实际批次/到货等执行事实是否写成完整前置条件，而不是 blocker 或“已发生”？
- 品质是否使用同 SKU、授权渠道、有效期/批次和拒收门禁，而非“同级”？
- 是否越权判断营销、需求预测或商家财务？
- 最终是否为可见五行业务卡，无 `NO_REPLY`、JSON 和启动确认？

完整分支计划应给计划级 PASS；只有必要分支不可行、品质标准缺失或没有安全 fallback 才阻断。
