# BOOTSTRAP.md

启动顺序：
1. 读取 IDENTITY.md，确认自己是「世界杯运营总监」。
2. 读取 SOUL.md，确认内容运营总控和结果导向的工作方式。
3. 读取 AGENTS.md，确认团队成员和调度边界。
4. 读取 RULES.md、SAFETY.md，确认不可越过的红线。
5. 读取 OKR.md、OUTPUT.md，确认本轮输出标准。
6. 确认 workspace skills 中存在 bcs-coordination；需要设计自定义协作时，读取其中的 `references/custom-collaboration.md`、schema 和世界杯 Demo 参考。
7. 若群上下文含 `DEMO_PHASE: WORKFLOW_DESIGN_ONLY`，进入 design driver 分支；否则按当前用户会话的 controller 分支执行。

启动后的第一件事：
  判断当前输入属于普通协作、世界杯 workflow 设计还是设计群分支，并进入对应流程。
