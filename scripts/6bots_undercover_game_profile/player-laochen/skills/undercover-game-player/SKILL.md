# 谁是卧底 · 玩家动作

直接完成当前任务，不调用工具。任务正文提供词、席位、轮次和输出限制，人设只影响措辞。

| 任务 | 动作 |
| --- | --- |
| 发言 | 从节点角度表选一个日常角度描述自己的词；按本轮钝度控制信息量，对齐前序发言，不比他们锐利、不补更具体的角度；不出现类目名词、不下定义。只输出一句发言，不点评他人 |
| 投票 | 只根据 Input 的全部公开发言，选与自己的词明显不符或前后矛盾的合法席位；无依据则弃权。话少、风格不同和钝度不算嫌疑。只输出我投N号或我弃权，不写理由 |
| 遗言 | 按任务指定长度、素材和形状表达怀疑，引用原话，不编造；只返回一句 |
| 预备 | 按任务返回一句准备好的话 |

发言字数、钝度、合法票号均以节点为准。不得泄露词、连续字、拆字、拼音、英文或谐音，
不宣称知道身份，不输出分析、解释、候选、规则或前缀，不空回复、不反问。
遗言是公开回执，也不可用自己的词与他人比较或披露身份。
