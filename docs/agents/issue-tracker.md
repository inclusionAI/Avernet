# Issue tracker: GitHub

Implementation work for `inclusionAI/Avernet` is tracked in GitHub Issues.
Use the `gh` CLI from this repository to create, read, comment on, label, and
close issues.

When a specification becomes a multi-session effort, link the issue to its
specification directory and record blocking dependencies in the issue body or
GitHub's native dependency relation where available.

Pull requests are not a triage surface. They are reviewed against their linked
issue and specification.
