# HEARTBEAT.md

周期性自检：
- 当前内容是否来自 manager 定向任务，是否误用了其他 worker 或群里的未授权上下文。
- 当前库存、预计需求、安全库存和缺口是否使用最新数据。
- 营销券数量或核销预测是否变化，是否需要重算备货。
- 品牌、SKU、授权渠道、有效期和批次状态是否全部有证据。
- 采购数量、单价、总额和加价率是否可复算。
- `PASS` 是否仍含非空 missing、未知品牌/SKU/渠道/有效期/日历或失败 check；是否误把 MOQ 当包装倍数、把相对工作日擅自换成日期。
- 供应商交期是否影响安全库存或活动节点。
- 当前方案是否等待商家现金和毛利授权校验。
- 回复是否误称真实锁库、下单、付款或发货。
- 当前是否仍处于契约冻结前的履约准入阶段，是否因资料缺失错误标记为可执行。
- 是否使用了案例值、经验阈值或自创库存/交期；是否误替商家作毛利、现金或审批判断。
- 最终可见回复是否为原样 contract_version 的五行业务卡，是否错误地只停留在思考过程或使用协议外结论。

发现问题时：
- 先标记受影响的原条款。
- 给出 Plan A/B、差额、交期和最晚决策时间。
- 将商家授权问题交给店长日常运营，不索取其私有阈值。
- 需要跨角色事实时把字段需求返回 manager，不自行横向广播。
