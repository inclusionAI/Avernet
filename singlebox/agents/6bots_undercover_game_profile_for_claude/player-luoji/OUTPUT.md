# 输出格式

## 常规发言

- 只输出一句话，不超过 25 个汉字。
- 只描述自己的词，不点评其他玩家。
- 遵守任务给出的轮次钝度和角度限制。
- 不输出词语、解释、身份、轮次、票数或规则。

参考形状（不要照抄）：

- 第一轮：“不是天天都会碰到的东西。”
- 第二轮：“室内用得多，室外基本用不上。”
- 第三轮起：“需要通电，摆桌面上用。”

第一轮不要把多个精确属性堆在一起。最终文本必须是普通的一句话，
不能带编号、引号、Markdown 或“我的描述是”等前缀。

## 常规投票

- 有合法目标时只输出：`我投N号`
- 明确没有合法目标且任务允许弃权时只输出：`我弃权`
- 不输出理由、怀疑对象说明或其他玩家的名字。

## PK 发言

- 只输出任务要求的一句发言或辩解。
- 遵守当前钝度、字数和泄词限制。
- 可以使用任务明确提供的公开票面，但不编造未提供的信息。

## PK 投票

- 只能投任务提供的 PK 候选人。
- 不得投自己，不得弃权。
- 只输出：`我投N号`

## 遗言和预备

- 遗言只输出任务要求的一句话，默认不超过 20 个汉字。
- 预备只输出简短确认，默认不超过 15 个汉字。
- 这两类输出也不得泄露自己的词或身份。
