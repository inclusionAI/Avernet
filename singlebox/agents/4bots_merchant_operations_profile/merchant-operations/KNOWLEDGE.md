## 必要计算口径

所有数字标记来源：`TASK_FACT`、`KNOWLEDGE_FACT`、`OWNER_COMMITMENT`、`DERIVED` 或 `DECISION_VARIABLE`。只有前四类可作为确认事实；推导必须保留公式、单位和时间窗。

营销结算：

- 优惠额 = 门市价 - 用户实付。
- 平台补贴 = 优惠额 × 平台确认承担比例。
- 商家结算收入 = 用户实付 + 平台补贴。
- 平台预算占用 = 单次平台补贴 × 最大核销量。
- 贡献毛利率 =（商家结算收入 - 交易服务费 - 变动履约成本）÷ 商家结算收入。

库存：

- 活动可用库存 = 账面可用 - 常规预留 - 安全库存 + 可按时到货的在途。
- 完整耗材义务 = 套餐销量 × 3。
- 缺口 = `max(完整义务 - 活动可用库存, 0)`。
- 缺口大于 0 时最小采购量 = `max(缺口, MOQ)`；只有 owner 给出包装倍数才再向上取整。
- 同一在途只能在桥接中计算一次。当前按时到货分支活动可用为 `90-45-15+20=50` 份；这不是销量承诺。

产能：

- 剪发增量分钟 = 增量核销次数 × 45。
- 护理完整分钟 = 套餐销量 × 3 × 60。
- 整体增量分钟 = 各服务增量分钟之和；与同周期整体剩余分钟比较。
- 产能缺口 = `max(需求分钟 - 可用分钟, 0)`；正的 `可用-需求` 只能叫剩余产能，不能叫负缺口。
- 最终 PASS 要求整体人员池、技能池和工位池均无缺口。

现金占用只计算回款前实际支付的增量现金（如采购预付、押金、已确认临时用工），不把券面优惠或收入减少自动当现金支出。

工作日交期缺少下单日、截止时间、供应商日历或节假日口径时，只保留相对交期，不编造具体日期。
